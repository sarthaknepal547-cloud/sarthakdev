A private editor for sarthakdev.com.np. Add photos, songs and posts from this phone — no laptop needed.

One-time setup — about 3 minutes
  1. Open github.com in this browser and sign in as sarthaknepal547-cloud.
  2. Tap your avatar → Settings → scroll to Developer settings → Personal access tokens → Fine-grained tokens.
  3. Tap Generate new token. Name it studio, set expiry to 1 year.
  4. Repository access → Only select repositories → pick sarthakdev.
  5. Permissions → Repository permissions → Contents: Read and write.
  6. Tap Generate token, copy the github_pat_… line, and paste it below.
