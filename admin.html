Owner sign-in

This page lets you edit your website. It does nothing without your own GitHub key — visitors see a blank login and nothing else.

How to get a key (one time, 2 minutes)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token
  3. Repository access: Only select repositories → sarthakdev
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate, copy it, paste it above

The key is stored only in this browser. Revoke it any time on GitHub to cut off access instantly.
